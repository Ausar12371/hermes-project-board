# 大鲸鱼 · Hermes 项目分类插件

> **项目分类台（Project Board）** —— 给 **Hermes Agent 桌面端**做的运行时插件：把你和 AI 一起折腾过的项目摊成卡片，**让模型自动归到六类里**，点一下就能顺着上下文接着干。

和 AI 协作久了，磁盘上会攒下一堆半截项目：站点建了一半、脚本写了个开头、视频修到 80%……这个插件就是给它们建的**停放坪**。

## ✨ 功能

- **AI 全自动分类** —— 首次装载自动把清单交给模型分类；之后可手动「AI 分类」（补未归类的 / 整盘重排）。批量添加时还能顺手分类那一批。
- **固定分类 + 归档** —— 网页 / 插件 / 程序 / 游戏 / 项目 / 杂活，外加第七类**归档**（专收"完事了"和"先搁着"的）。分类写死不用纠结；含义写在源码顶部 `CATS`，也一并喂给模型当判定依据。
- **可调列宽** —— 拖列边缘就能调宽度（172~560px），双击边缘恢复默认，宽度会记住。布局终于像终端窗口一样随手可调。
- **归档** —— 每张卡片右上角有一个 **📦 归档按钮**（点一下就从主视野"下班"，归档中的卡片按钮变成 ↩ 取回）；顶部工具栏的「**归档 · N**」开关控制归档列的显示。归档**只认人工**：AI 分类永远不会自动把项目扔进归档。
- **点一下接着干 ▶** —— 卡片上的「继续处理」会：新建会话 → 跳到会话 → 自动递上开场消息（项目名 / 分类 / 路径 / 你的标注）。**路径是真实盘符目录时，同时会成为新会话的工作区**，AI 一进去就站在项目里。
- **选择模式 ☑** —— 勾几张卡，批量「归到…」或「删除选中」（删除前列出清单、二次确认；没勾的一个不碰）。
- **日常操作** —— 拖卡片换分类 · 点徽章直选分类 · 备注即改即存 · 星标 · 搜索（名/路径/标注） · 新建 / 批量添加（一行一个） · 导入导出 JSON 备份。

## 📦 安装

需要 **Hermes Agent（桌面端）**。

1. 找到你的 Hermes home：
   - Windows 默认：`%LOCALAPPDATA%\hermes`
   - macOS / Linux 默认：`~/.hermes`
   - 或在终端里问它：`hermes --version`（会打印安装目录）
2. 在 `<HERMES_HOME>/desktop-plugins/` 下建一个 `project-board` 文件夹，把本仓库的 `plugin.js` 放进去：
   ```
   <HERMES_HOME>/desktop-plugins/project-board/plugin.js
   ```
3. 在 Hermes 里按 `Ctrl+K`（macOS 是 `⌘K`）→ 搜「Reload desktop plugins」执行；或者干脆重启 Hermes。
4. 侧边栏会出现「**项目分类台**」入口（`Ctrl+K` 搜「分类」也能直达）。

> 装好自带 3 条**示例**卡片，随手删掉，换成你自己的项目即可。

## 🤖 AI 分类是怎么工作的

- 走 Hermes 网关的一次性模型调用 `llm.oneshot`，**用你自己配置的模型**——插件里没有任何写死的模型名、没有 API Key、不联网到第三方。
- 首次装载清单为空分类时自动跑一次（等网关就绪 4 秒）；失败自动重试，仍失败则退回内置兜底，并记录标记，不会反复消耗模型。
- 输出解析很皮实：干净 JSON、带 markdown 代码块、带前后废话、逐行「序号=分类名」都能吃。
- 换台电脑？把 `plugin.js` 拷过去就行，AI 分类会用**那台机器自己的模型配置**。

## 🔒 数据与隐私

- 所有数据存本机 Hermes 的 localStorage（键：`hermes.plugin.project-board.board-v3`），不上传任何服务器。
- 唯一的外呼是 AI 分类时经你本机 Hermes 网关的模型调用。
- 初始清单只有 3 条通用示例，不含任何个人信息。

## 🛠 排障

- 插件加载失败会在界面上弹 toast（含错误名）。
- 想深挖：插件会往 renderer console 打 `[project-board]` 前缀的诊断日志（error 级），会收进 `logs/desktop.log`。
- **改了代码不生效？** 先看 Hermes 窗口是不是最小化了——最小化时 renderer 被节流，插件热重载不会落地。恢复窗口，或 `Ctrl+K` → Reload desktop plugins。
